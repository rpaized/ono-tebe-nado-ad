# Оно тебе надо

Проектная работа Яндекс Практикума: вёрстка одностраничного сайта аукциона вещей, в которые никто не верил.

Ссылка на репозиторий: https://github.com/rpaized/ono-tebe-nado-ad

## Как открыть

Откройте `index.html` в браузере, сервер не нужен. Страница свёрстана под ширину экрана 1100 px и больше.
